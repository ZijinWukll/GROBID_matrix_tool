# 变更记录

## 2026-11-06 - 单一自动构建入口与命令职责收敛

- build 固定扫描 seed_papers，移除目录外累加和自定义扫描参数；有效旧 TEI 自动复用，损坏缓存自动补建。
- 新增 import 仅导入、export 仅离线 JSON 快照导出、cache 显式预览/清理；add/rebuild 兼容为 import/export，remove 退役。
- 分类使用短请求编号、JSON 围栏恢复和小批次有限补救；低置信候选自动检查一次，分歧仍保留不确定状态。
- 翻译处理所有缺译，不再受 500 句截断；空回复、截断和标记丢失自动有限补试。
- 可选人工工具仅读写快照与覆盖，不触发额外模型处理；缓存清理保护 PDF、短名、译文池及人工结果。

## 2026-11-05 - 翻译统计与固定语料回归边界

- “方法名 + 多列数值”的表格片段不再被计为缺译，带数字的正常英文句子仍需翻译。
- 固定语料回归继续严格比较冻结论文及每条旧译文，允许新增译文和调整模型运行参数，不覆盖私有基线。

## 2026-11-05 - 当前 PDF 范围同步与模型失败快速出表

- `build` 默认只纳入当前扫描目录中的可用论文，替换 PDF 后不再混入旧论文；保留历史缓存，支持放回 PDF 复用。
- 新增 `build --keep-existing` 保留累加方式；`add`、`rebuild` 保持原有范围语义。
- 新增 `--no-llm`，跳过模型分类及翻译后直接生成；提供抽取完成、分类批次、翻译句数和 Excel 写入进度。
- 禁用模型 SDK 隐式重试，连接超时 5 秒；请求异常后停止本轮连续调用，使用待复核标签及英文继续出表。
- 分类按批、译文按 10 句及结束/中断保存；失败兜底后续可重试，避免网络错误被当作永久成功缓存。
- 缺失或失败标签在矩阵中显示“待分类｜待复核”，避免把临时兜底显示成正式 M/I 结论。
- 回归继续检验原冻结语料，独立于当前 PDF 选择；不改写私有回归基线。

## 2026-11-05 - PDF 文件夹一键构建与首次初始化修复

- 新增 `build`：默认扫描 `data/seed_papers/`，支持 `--input-dir`，批量增量解析后统一导出一次。
- `build` / `add` 首次自动创建空项目；普通 `init` 不再依赖三篇历史论文缓存，旧迁移保留为 `init --migrate-legacy`。
- `init --force` 改为补齐缺失配置，保留已有项目与人工规则；显式旧迁移的 `--force` 仍会替换登记表。
- PDF 内容哈希与 TEI 缓存用于跳过重复解析，中文文件名生成稳定短名，保留自定义短名和表头。
- 批量解析失败时保存成功结果、返回失败状态，修复后可重跑续接；保留原有单篇、离线、重建和人工复核命令。
- 修复单篇添加时 TEI 缺失无法修复、同名 PDF 覆盖其他论文归档、旧短名被重复登记的问题；扩展 PDF/TEI 忽略规则以覆盖自定义输入目录。
- 同步命令帮助、快速开始、排障文档和无网络依赖的工作流测试。

## 2026-09-12 - 引用关系标签

- 新增 B&E、S&S、C&A、Q&A、M/I 五类单元格关系标签。
- 标签按本地 vLLM 批量分类，先分类后翻译，结果按内容哈希缓存。
- Excel 单元格以局部粗体显示【中文名｜代码】。
- 新增 `export-labels` / `import-labels` 人工校对闭环和 `rebuild --relabel`。
- 复核阈值调整为 0.60，默认只导出待复核单元格；全量导出使用 `--all`。
- 重写 README、AGENTS 和专题手册，帮助首页增加快速开始与命令分组。
- GROBID 地址迁移到 `.env` 的 `MATRIX_GROBID_URL`，示例配置不再保存学校 IP。

## 2026-09-12 - 本地 LLM 翻译

- 自动翻译后端由 MyMemory 切换为 OpenAI 兼容的学校本地 vLLM。
- 新增 `.env` 配置入口，连接地址、密钥和模型 ID 不再硬编码。
- 新增本地翻译参数、写回流程和非语言片段过滤测试。
- 使用 `Qwen2p5` 补全当前矩阵表缺译句。

## 2026-09-10 - 项目层级重构

- 源码迁入 `src/`，保留根目录 `matrix_tool.py` 兼容入口。
- 配置、状态、种子论文和导出物统一迁入 `data/`。
- 新增 pytest 冒烟测试与逻辑结果回归基线。
- 新增 `log/matrix_tool_YYYYMMDD.log` 按日 JSON Lines 运行日志。
- 移除 `render_qa.py` 与 PDF 预览流程，人工直接审查 xlsx。

## 2026-11-06 - 帮助、文档与项目整理

- 完整补齐命令格式与示例，新增统一命令参考，缩短 README 和操作入口。
- 构建改为五阶段，分类/翻译按约十秒节流刷新，结束仅显示关键结果。
- 删除无调用的旧比较辅助函数；清理生成的测试临时副本及 Python/pytest 缓存，保留正式测试与研究数据。
